# User guides

Task-oriented guides for building with n8n Agent DDD, kept next to the code they describe.

- Reference documentation: `documentation/` (published).
- Internal engineering documentation: `docs/` (not published).

Planned guides:

- `getting-started/`: run the local stack
- Build your own domain agent, starting from `templates/domain-pack/` with Tunisia DTC as the worked example
- Write a channel or commerce adapter
- Add tests for your domain
- Deploy and operate
