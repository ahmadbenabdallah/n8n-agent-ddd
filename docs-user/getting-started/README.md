# Getting started

Until this guide is written, use:

- `README.md` in the repository root for the quick start and installation
- `documentation/getting-started/` for the concepts and the current maturity of the project
- `documentation/development/domain-development.md` for building your own domain pack from `templates/domain-pack/`

This folder will hold the hands-on guides: run the local stack, build your own domain agent, write a channel or commerce adapter, add tests, deploy and operate.
