# Release Archive Index

The release ZIPs built before this repository was put under git (v0.13.0 – v0.20.3, all built 2026-09-19) are published as assets of the GitHub release
[`archive-v0.13.0-v0.20.3`](https://github.com/ahmadbenabdallah/n8n-agent-ddd/releases/tag/archive-v0.13.0-v0.20.3).

They are kept for historical inspection only. Archives after v0.14.3 are delta overlays rather than full trees, so they cannot reproduce a release on their own. The repository's git history is the canonical source.
