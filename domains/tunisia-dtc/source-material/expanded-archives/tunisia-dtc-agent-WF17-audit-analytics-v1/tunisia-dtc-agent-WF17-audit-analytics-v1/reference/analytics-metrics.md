# Analytics metrics

Recommended derived metrics:

## Funnel
- inbound conversations
- qualified conversations
- product interest
- product selected
- cart add rate
- checkout start rate
- checkout confirmation rate
- verified purchase rate

## Reliability
- security block rate
- clarification rate
- escalation rate
- tool failure rate
- transaction verification failure
- duplicate action rate
- renderer regeneration rate
- average latency

## Sales
- assisted conversion
- average order value
- promotion usage
- cart abandonment

Never derive customer-sensitive metrics by exposing raw PII in analytics dashboards.
