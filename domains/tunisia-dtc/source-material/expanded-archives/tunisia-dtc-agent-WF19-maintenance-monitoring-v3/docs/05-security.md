# Security

- WF-19 cannot authorize customer actions.
- Maintenance inputs are untrusted.
- Health endpoints must not expose secrets.
- Operational dashboards should use least privilege.
- Security events should be summarized without exposing sensitive payloads.
- Automated remediation must use explicit allowlists.
- Never run arbitrary commands or URLs based on LLM output.
- Never let a monitoring alert become an instruction to change prices, stock, coupons or orders.
