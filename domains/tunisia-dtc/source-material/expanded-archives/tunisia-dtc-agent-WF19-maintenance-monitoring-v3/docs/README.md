# WF-19 Maintenance & Monitoring v3

Operational control plane for the DTC agent.

WF-19 is responsible for detecting and recording operational conditions. It does not silently repair business data or grant transaction authority.

## Domains

- WooCommerce health
- Supabase/database health
- n8n workflow failures/reconciliation
- KB freshness
- security-event monitoring
- maintenance/cleanup
- operational run history
