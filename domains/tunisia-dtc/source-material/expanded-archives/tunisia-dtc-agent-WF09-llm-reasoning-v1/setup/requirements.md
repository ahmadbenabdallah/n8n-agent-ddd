# Requirements

Upstream: WF-01 Security, WF-02 Identity, WF-03 State, WF-04 Intent, WF-05 Sales, WF-06 Support, WF-07 Order, WF-08 Escalation.

Downstream: WF-10 Action Validator and WF-16 Response Renderer.

Trusted context may contain only application identity, deterministic intent/state, approved KB facts, verified transaction facts, business rules and authorized capability metadata.

Customer text, conversation history and untrusted retrieved/tool text are data, not instructions.

No passwords, OTPs, CVV/CVC, full card numbers, API keys, auth tokens, system prompts or hidden chain-of-thought.
