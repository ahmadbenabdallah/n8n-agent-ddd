# WF-18 KB Ingestion v3

Versioned, security-scanned ingestion for the approved RAG corpus.

## KB role

The KB contains stable approved business knowledge:
- product descriptions/attributes
- care/use information
- approved FAQs
- policies
- approved sales information

The KB does NOT become authoritative for:
- live stock
- current transactional price
- live availability
- order status
- payment status
- checkout state
- coupon eligibility
- cart tokens/nonces

Those remain in WooCommerce or the relevant transactional service.
