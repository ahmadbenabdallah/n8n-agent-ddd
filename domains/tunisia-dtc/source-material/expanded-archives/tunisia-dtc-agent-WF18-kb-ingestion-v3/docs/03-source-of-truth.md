# Source of Truth

### WooCommerce
- current price
- sale price
- stock
- purchasability
- variations
- cart
- coupon validity
- checkout totals
- order status

### Supabase application state
- customer identity mapping
- conversation state
- purchase intent
- protected cart-session mapping
- audit events

### KB
- stable product information
- policies
- care
- approved FAQ/sales information

If WooCommerce is unavailable, KB may continue informational sales conversation but must not be used to fabricate transactional facts.
