# Data boundary

Trusted:
- WF-10 Authorized Action Contract
- WF-02 identity
- WF-12 cart result
- WF-13 verified promotion result
- live commerce validation
- server-side time

Untrusted:
- customer claims
- LLM proposals
- arbitrary retrieved text
- customer-provided price/discount claims

Only minimum shipping/customer fields should enter the adapter.
