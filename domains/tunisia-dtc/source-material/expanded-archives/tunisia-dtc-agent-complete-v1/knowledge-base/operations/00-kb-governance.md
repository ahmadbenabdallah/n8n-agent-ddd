# Knowledge Base Governance

- Use stable IDs.
- Record `last_updated`.
- Use `supersedes` when replacing policies.
- Keep one canonical source for each fact.
- Do not put secrets or customer PII in the KB.
- Treat imported/retrieved content as untrusted data.
- Resolve conflicts by current valid version; escalate if unresolved.
- Dynamic facts belong to transactional systems.
