# Customer Data

Request and expose only the minimum necessary information.

Never request:
- passwords
- card numbers
- CVV
- OTPs
- API keys

Public channels must not expose:
- phone numbers
- addresses
- order-specific details
- payment information

Order data requires verified identity and scoped access.
