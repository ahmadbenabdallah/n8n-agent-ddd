# Observability, Cost & Evaluation

## Per-turn telemetry

Correlation ID, conversation, intent, language, model, prompt version,
retrieval sources/scores, tools requested/executed, authorization
result, latency, tokens, cost, outcome and escalation.

## Sales KPIs

Assisted revenue, conversion, AOV, recommendation CTR, add-to-cart,
checkout and purchase.

## Support KPIs

Automation, resolution, escalation, repeat contact and human handling
time.

## Security KPIs

Injection signals, unauthorized actions, cross-customer attempts,
blocked tools, leakage attempts, poisoning detections and resource-limit
events.

## Evaluation

Offline → shadow → canary → production. Every
prompt/model/tool/RAG/business-rule change triggers regression tests.

## Cost controls

Budget by conversation, customer, day, workflow and model.
