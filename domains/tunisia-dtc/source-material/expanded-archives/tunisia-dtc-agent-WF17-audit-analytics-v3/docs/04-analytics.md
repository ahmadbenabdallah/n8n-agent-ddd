# Analytics Signals

Recommended metrics:

### Funnel
- conversations started
- product discovery rate
- product selection rate
- cart-add rate
- checkout-start rate
- checkout-confirm rate
- COD order creation rate

### Reliability
- WooCommerce availability
- WF failure rate by workflow
- timeout/retry rate
- idempotency replay rate
- post-action verification failures

### Security
- blocked actions
- authorization denials
- prompt-injection/security flags
- renderer safety violations
- suspicious repeated attempts

### Knowledge
- KB fallback rate
- KB retrieval failures
- source freshness events
- unanswered/low-confidence information requests

Avoid using raw PII as analytics dimensions.
