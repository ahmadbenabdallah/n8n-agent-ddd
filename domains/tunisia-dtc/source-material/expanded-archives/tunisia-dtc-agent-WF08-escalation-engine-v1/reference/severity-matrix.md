# Escalation severity matrix

| Severity | Examples | Handoff |
|---|---|---|
| Critical | immediate danger, serious safety incident, account takeover, urgent security incident | immediate_human |
| High | payment dispute, fraud claim, legal threat, privacy/security incident | priority_human |
| Medium | ordinary complaint, damaged/defective claim, human request | human_queue |

This is a deterministic operational priority, not a claim about the customer's credibility.
