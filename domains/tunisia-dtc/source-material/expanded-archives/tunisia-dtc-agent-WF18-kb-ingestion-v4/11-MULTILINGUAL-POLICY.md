# Multilingual KB Policy

The KB can contain:
- Tunisian Arabic;
- Arabic;
- French;
- English;
- mixed language;
- Latin/Arabizi.

Language and script metadata are stored independently.

Retrieval does not dictate the customer's response script.

WF-09/WF-16 must use the conversation's canonical language/script state.

For Latin/Arabizi customer conversations, customer-facing rendering must remain Latin unless explicitly requested otherwise.

Cross-language retrieval is allowed when semantically useful, but the final answer must obey the conversation language/script policy.
