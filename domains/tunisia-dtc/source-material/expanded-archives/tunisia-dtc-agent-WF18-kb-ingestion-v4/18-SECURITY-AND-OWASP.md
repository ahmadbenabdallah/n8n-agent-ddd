# WF-18 Security & OWASP Controls

### Prompt Injection
Retrieved text is data, never instruction authority.

### Sensitive Information Disclosure
Scan and redact credentials/secrets before indexing.

### Data/Model Poisoning
Approval, provenance, checksum and quarantine controls.

### Vector/Embedding Weakness
Version embeddings, validate dimensions, isolate production index.

### Misinformation
Versioned approved sources + live-data separation.

### Excessive Agency
WF-18 has no commerce privileges.

### Supply Chain
Pin parser/chunker/embedding versions and record them.

### Unbounded Consumption
Limit document size, chunk count, embedding batch size and retries.

### Insecure Output Handling
Retrieval payload is structured and provenance-bound.

### Access Control
Separate ingestion/admin roles from customer-facing retrieval.
