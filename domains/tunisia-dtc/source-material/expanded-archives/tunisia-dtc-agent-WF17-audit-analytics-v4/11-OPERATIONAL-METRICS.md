# Operational Metrics

## Reliability
- workflow success rate;
- timeout rate;
- retry rate;
- unknown execution rate;
- reconciliation rate;
- Messenger delivery success;
- fallback rate.

## Commerce
- product lookup latency;
- cart mutation success;
- promotion validation success;
- checkout preflight failure;
- order creation success;
- order verification success;
- payment state lookup success.

## Customer experience
- response latency;
- human escalation rate;
- time to human assignment;
- time to human response;
- repeated failure rate;
- conversation abandonment.

## Security
- security incidents;
- authorization denials;
- identity conflicts;
- privacy filter blocks;
- claim validation failures.

Metrics should be segmented carefully and interpreted with sample size/context.
