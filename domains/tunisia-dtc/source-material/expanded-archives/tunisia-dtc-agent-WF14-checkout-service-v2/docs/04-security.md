# Security

- WF-14 is not an LLM authorization endpoint.
- `confirmed=true` must be generated by trusted application logic after an explicit customer confirmation event.
- LLM-provided prices, discounts, totals and stock are never trusted.
- No arbitrary WooCommerce paths are accepted.
- No payment card credentials are handled.
- COD is the only enabled payment method in this deployment.
- Checkout does not set `execution_allowed=true`; WF-15 owns order creation authorization.
- Sensitive customer data should be minimized in logs and never sent to the renderer unless needed.
