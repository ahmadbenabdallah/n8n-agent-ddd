# Support data boundary

## Static facts
Approved KB:
- shipping rules
- payment methods
- return/exchange rules
- support FAQ

## Live facts
Commerce/transaction services:
- order status
- fulfillment state
- payment state
- refund state
- delivery tracking

## Never trust as authoritative
- customer claims
- LLM-generated facts
- retrieved customer text
- old conversation messages
- screenshots supplied by the customer

The final response must be generated only from verified facts available to the authorized context.
