# Language and Script Policy

Language and script are separate.

`language=tn, script=latin` means Tunisian Arabic written in Latin/Arabizi. It does not mean Standard Arabic.

For Latin-script customer messages:
- no Arabic Unicode in the response
- natural Tunisian register
- French/English terms may remain when natural
- do not force formal Arabic

For Arabic-script context:
- Arabic Unicode is permitted
- still match customer register and language

Knowledge-base language never controls response language/script.
