# WF-18 Security / OWASP Controls

### LLM01 Prompt Injection
Documents are data, never control instructions.

### LLM02 Sensitive Information Disclosure
Secret/sensitive scanning and access controls.

### LLM03 Supply Chain
Approved source registry and versioned embedding pipeline.

### LLM04 Data/Model Poisoning
Approval, provenance, quarantine and rollback.

### LLM05 Improper Output Handling
Retrieved content is untrusted and cannot directly trigger tools.

### LLM06 Excessive Agency
WF-18 has no commerce execution privilege.

### LLM07 System Prompt Leakage
Source content cannot retrieve hidden prompts.

### LLM08 Vector/Embedding Weakness
Metadata filters + provenance + approved-version constraints.

### LLM09 Misinformation
No KB-only override of live commerce facts.

### LLM10 Unbounded Consumption
Bound document size, chunk count, embedding calls and retries.
