# Definition of Done — WF-18 v4

WF-18 is production-ready only when:

1. Only approved sources can publish.
2. Every chunk has provenance.
3. Document versions are explicit.
4. Supersession is deterministic.
5. Poisoned/injected content is quarantined.
6. Secrets are removed before indexing.
7. Static KB cannot override live commerce truth.
8. Dynamic price/stock/order/payment facts remain live-service responsibilities.
9. Retrieval returns provenance and effective-date metadata.
10. Embedding/parser/chunker versions are recorded.
11. Ingestion is idempotent.
12. Partial failures cannot produce false publication.
13. RLS/least privilege is configured.
14. Rollback is tested.
15. Red-team and E2E suites pass.
16. WF-17 receives ingestion/publication/security audit events.
