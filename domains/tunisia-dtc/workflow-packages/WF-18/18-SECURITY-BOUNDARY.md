# WF-18 Security Boundary

WF-18 may:
- ingest;
- validate;
- scan;
- normalize;
- chunk;
- embed;
- index;
- publish approved knowledge.

WF-18 may not:
- authorize commerce actions;
- create orders;
- modify carts;
- change payment state;
- elevate identity;
- release human ownership;
- override WF-10;
- bypass WF-20.

RAG is a knowledge dependency, not a permission system.
