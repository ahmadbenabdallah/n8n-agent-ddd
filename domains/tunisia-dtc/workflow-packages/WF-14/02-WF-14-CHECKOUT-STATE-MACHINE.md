# WF-14 Checkout State Machine

`CART_READY`
→ `CHECKOUT_STARTED`
→ `PREFLIGHT_VALIDATING`
→ `CHECKOUT_READY`
→ `ORDER_SUBMISSION_AUTHORIZED`
→ `ORDER_CREATING`
→ `ORDER_CREATED_UNVERIFIED`
→ `ORDER_VERIFIED`
→ `COMPLETED`

Failure/recovery states:
`VALIDATION_FAILED`
`OUT_OF_STOCK`
`PROMOTION_INVALID`
`TOTAL_CHANGED`
`CHECKOUT_INVALID`
`COMMERCE_UNAVAILABLE`
`UNKNOWN_EXECUTION`
`RECONCILIATION_REQUIRED`

The model cannot move the state machine.
WF-03/WF-10/WF-14 deterministic logic controls transitions.
