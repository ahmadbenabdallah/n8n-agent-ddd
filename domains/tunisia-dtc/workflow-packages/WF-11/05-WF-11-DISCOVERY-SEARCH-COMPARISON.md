# WF-11 Discovery, Search and Comparison

## Discovery
Search can use approved product metadata and current availability where needed.

Search results are bounded:
- maximum result count;
- maximum field length;
- no hidden/private WooCommerce metadata.

## Comparison
Comparison responses must use normalized facts from authoritative sources.

If a requested comparison fact is unavailable, state that it is unavailable rather than infer it.

## Recommendations
WF-11 can provide candidate products based on explicit customer requirements and approved product data.

It must not:
- fabricate product superiority;
- invent reviews;
- invent stock;
- invent discounts;
- claim guaranteed suitability without evidence;
- use customer-private data outside permitted context.

WF-05 owns sales strategy; WF-11 supplies product facts/candidates.
