# Security Analytics

Track security-relevant categories:

- prompt injection attempts;
- sensitive-data disclosure attempts;
- identity abuse;
- unauthorized order access;
- parameter tampering;
- tool misuse;
- stale-state execution attempts;
- replay/idempotency violations;
- suspicious automation volume;
- repeated failed verification;
- escalation bypass attempts;
- secret injection;
- policy violations.

Useful dimensions:
- workflow;
- channel;
- action type;
- attack category;
- severity;
- outcome;
- model/prompt version;
- time window.

Do not expose security detection details to the customer.
