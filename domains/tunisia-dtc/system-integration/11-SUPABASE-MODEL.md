# Integrated Supabase Model

Core domains:

## Identity
- customer identities;
- channel identities;
- commerce identity links;
- order scopes.

## Conversation
- conversation state;
- ownership;
- automation mode;
- escalation reference.

## Human
- human cases;
- case events.

## Knowledge
- KB sources;
- documents;
- chunks;
- approvals;
- ingestion runs.

## Audit
- audit events;
- action audit;
- security events;
- response delivery records.

## Idempotency
- action idempotency;
- response delivery idempotency;
- event ingestion idempotency.

RLS and least privilege apply by domain.
