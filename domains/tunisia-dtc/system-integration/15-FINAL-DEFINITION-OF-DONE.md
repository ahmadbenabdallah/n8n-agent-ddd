# Final Definition of Done — Tunisia DTC Agent v4

The integrated system is production-ready only when:

1. WF-00 → WF-20 contracts are versioned.
2. WF-10 is the only authorization boundary.
3. WF-20 is the only privileged WooCommerce boundary.
4. Identity and order scope are deterministic.
5. Human ownership can pause AI automation.
6. LLM remains proposal-only.
7. KB is approved/versioned/provenance-bound.
8. Static KB and live commerce truth are separated.
9. Consequential actions are idempotent.
10. Commerce mutations are post-verified.
11. Unknown executions enter reconciliation.
12. COD order/payment semantics are preserved.
13. WF-16 blocks unsupported/hallucinated claims.
14. Privacy and secret controls cover all customer-facing paths.
15. WF-17 provides durable auditability.
16. WF-19 provides health, drift, alerting and recovery.
17. Red-team/E2E tests pass.
18. Deployment and rollback are tested.
19. Disaster recovery is validated.
20. No workflow can silently bypass a higher-trust boundary.
