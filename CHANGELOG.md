# Changelog

All notable changes to n8n Agent DDD are documented here.

The project follows a phased pre-1.0 release model. Version numbers represent architectural milestones and do not, by themselves, imply production certification.

## [0.20.3] — ReadMe bi-directional documentation architecture

### Added

- Professional root README architecture.
- Dedicated public documentation repository model.
- ReadMe bi-directional synchronization architecture.
- Public/internal documentation boundary.
- Documentation synchronization validation.

### Clarification

The repository prepares the Git/ReadMe architecture but does not claim that a live GitHub ↔ ReadMe connection has been executed.

## [0.20.2] — Documentation audit and privacy boundary

- Audited public and internal documentation boundaries.
- Refreshed public documentation for the 0.17–0.20 platform evolution.
- Strengthened public documentation publishing boundaries.

## [0.20.1] — Public documentation foundation

- Added public documentation structure.
