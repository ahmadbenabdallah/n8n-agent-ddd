# n8n Upstream Skills

This directory is an integration reference, not an uncontrolled copy of upstream code.

Canonical upstream source:
- https://github.com/n8n-io/skills

The project consumes or mirrors permitted upstream skill definitions only after:
1. license review;
2. version/commit pinning;
3. attribution;
4. security review;
5. compatibility validation.

Local DDD/security skills remain canonical for this repository.
